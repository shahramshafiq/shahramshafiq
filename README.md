## About

I completed a three-month Junior AI Engineer internship (Aug to Nov 2026) and study Computer Science at FAST NUCES. I like LLM systems that are measured, guarded and built to keep running, not just demos. Here is what I have built and learned:

- **Real-time voice agents:** streaming speech-to-text, LLM and text-to-speech pipelines with barge-in, then the same booking assistant rebuilt on the Gemini Live speech-to-speech API ([gemini-live-booking-assistant](https://github.com/shahramshafiq/gemini-live-booking-assistant)) and as a phone line through Twilio ([twilio-voice-booking-assistant](https://github.com/shahramshafiq/twilio-voice-booking-assistant)). I tuned latency stage by stage and measured it.
- **Tool calling that changes real data:** assistants that read and write Google Calendar, with a spoken confirmation before any change, idempotent writes and guardrails written in code.
- **LLM backends:** async FastAPI services with conversation memory, Valkey caching and rate limiting, server-sent events and background jobs.
- **Retrieval-augmented generation:** corrective RAG over SEC filings with cited answers and abstention ([sec-filings-rag-qa](https://github.com/shahramshafiq/sec-filings-rag-qa)), and multimodal RAG over PDF text, charts and maps ([multimodal-rag-pdf](https://github.com/shahramshafiq/multimodal-rag-pdf)), scored on a 71-question golden set (70/71 against 41/71 for text-only retrieval).
- **AI that stays honest:** [lab-kee-zubaan](https://github.com/shahramshafiq/lab-kee-zubaan), built in one day at an AI hackathon. A rules engine decides every lab result, the AI only writes the explanation, and a checker rejects invented numbers, in English, Urdu and Roman Urdu.
- **MCP and agents:** tool servers with NeMo Guardrails tested against jailbreak and prompt-injection attempts, and multi-agent pipelines in LangGraph such as [DevMind](https://github.com/shahramshafiq/devmind).
- **Also:** computer vision and automation (OpenCV, MediaPipe, OCR, Playwright), and fundamentals built from scratch in C++, Java, Python and x86 assembly.
